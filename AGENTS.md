# Project Rules

## Keep the Index Up to Date

Whenever you add a new page (`.html`, `.md`, or a directory containing an `index.html`) to this repository, update `index.md` to include a link to it:

- Place the link under the most appropriate existing section (`Trackers & Tools`, `Notes & Guides`, or `Demos & Browser Tests`), or add a new section if none fit.
- Use a concise, descriptive link title and a relative path matching the existing style (e.g., `[Page Title](page.html)`, `[Guide Title](guides/guide.md)`, or `[App Title](subdir/)`).
- If a page is renamed or removed, update or remove its entry in `index.md` accordingly.
